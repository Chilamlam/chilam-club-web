# 2026-08-29 工作日志

## 修复投资作业本页面 TypeError 崩页（commit 91bb61a）

**现象**：Streamlit Cloud 上「投资作业本」整页崩溃，traceback 指向
`app.py:512  st.image(info['avatar'], use_column_width=True)` → TypeError。

**根因**：Streamlit 新版本已彻底移除 `st.image` 的 `use_column_width` 参数
（历史演进：`use_column_width` → `use_container_width`(deprecated, 2025-12-31 移除)
→ `width="stretch"`）。`requirements.txt` 里 streamlit 未锁版本，Streamlit Cloud
自动升级到 1.5x/1.6x 后旧参数直接报错，导致整页白屏。

**修复**：
- 新增 `ui_compat.py` → `image_stretch(image, **kwargs)`：按
  `width="stretch"` → `use_container_width=True` → `use_column_width=True` → 默认
  顺序 try/except TypeError 降级，任何 Streamlit 版本都不崩。
- `app.py` 两处大佬头像（512/529 行）、`pages/dashboard.py` 四处收款码
  （微信/支付宝各 2 处）全部改用 `image_stretch`。
- `requirements.txt`：`streamlit` → `streamlit>=1.49,<2.0`。
- 新增 `tools_check_st_api.py`：AST 遍历全仓库所有 `st.xxx(...)` 调用，
  用 `inspect.signature` 比对关键字参数在当前装的 Streamlit 版本是否还存在。
  用法：`python tools_check_st_api.py .`。实测 1.62.0 下全仓库 0 处不兼容。

**验证方式**（可复用）：
1. 建独立 venv 装目标版本：`python -m venv .../envs/stcheck` +
   `pip install -i https://pypi.tuna.tsinghua.edu.cn/simple streamlit==1.62.0`
   （官方源在本机会 ConnectionResetError 10054，必须走清华镜像）。
2. 跑 `tools_check_st_api.py .` 做静态扫描。
3. 写临时冒烟页只渲染出问题的组件，`streamlit run _smoke.py --server.headless true
   --server.port 8899`，curl 取 HTTP 200 且日志 0 条 traceback，然后删掉临时页。

（packed-refs 停在旧值），照旧 `printf <sha> > .git/refs/remotes/origin/main` +
`git merge --ff-only`，快进到 Actions 的 `00d0001`（13 个 data 文件，含 7 个

远端 head = `91bb61a`（已用 GitHub API 核验）。
