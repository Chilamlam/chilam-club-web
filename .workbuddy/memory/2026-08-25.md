# 2026-08-25 工作记录

## 项目接入与代码架构学习: chilam-club-web

### 1. 架构总览
- **前端交互**: Streamlit 多页面仪表盘 (`app.py`, `page_core_driver.py`, `page_fibonacci.py`, `pages/auth.py`, `pages/dashboard.py`)。
- **定时调度与流水线**: GitHub Actions (`.github/workflows/daily_update.yml`)，每日北京时间 19:30 自动执行各量化分析脚本，更新 `data/` 目录并 push 回仓库。
- **量化策略与数据收集**:
  - `daily_rps_pro.py`: 欧奈尔 RPS 强势股计算（RPS_50, 120, 250）。
  - `daily_etf_pro.py`: 强势 ETF 动量分析。
  - `daily_market_monitor.py`: 全市场情绪、指数历史、行业热点及 Gemini AI 复盘分析。
  - `daily_speculation.py`: 可转债双低潜伏、妖债进攻、LOF/跨境 ETF 溢价套利。
  - `daily_guru_loader.py`: 顶级投资大师 13F / 国会交易明细追踪。
  - `daily_radar.py`: 核心龙头异动雷达。
  - `daily_snapshot.py`: 全市场每日快照。
- **用户与会员系统 (开发中/已规划)**:
  - `models.py` + `database.py`: SQLAlchemy + SQLite 模型定义 (User, Subscription, Payment)。
  - `auth.py`: JWT 鉴权与 bcrypt 密码加密。
  - `admin.py`: 后台会员与订阅管理。
  - `PLAN会员系统升级.md`: 会员体系规划文档。

### 2. 会员系统 Supabase 重构落地
- 完成基于 Supabase REST API 的持久化数据库迁移，解决 Streamlit Cloud 容器重启数据丢失问题。
- `database.py`: 标准库 `urllib` + `hashlib` (PBKDF2-HMAC-SHA256) 实现无冗余依赖的数据层。
- `auth.py`: JWT 鉴权与 Session 驱动的用户登录/注册/登出机制。
- `pages/auth.py`: 登录注册界面，支持一键登入与状态切换。
- `pages/dashboard.py`: 会员中心，展示 VIP 订阅有效天数与套餐方案。
- `admin.py`: 超级管理员后台，支持查看注册用户与手动开通 VIP。
- `app.py`: 侧边栏登录状态入口，强势股/投机套利/作业本页面 VIP 访问拦截卡片。
- `.github/workflows/daily_update.yml`: 增加每日向 Supabase 发送 Keepalive 请求，防止免费数据库休眠。
